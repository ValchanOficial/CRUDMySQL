# CRUD Spring Boot com MySQL

Este projeto é um exemplo de uma API RESTful simples usando Spring Boot e MySQL. Ele demonstra como realizar operações CRUD (Create, Read, Update, Delete) em uma tabela de usuários.

## Pré-requisitos

- Java 8
- MySQL

## Instalação

1. Clone o repositório:
```shell
git clone https://github.com/seu-usuario/seu-projeto.git
```

2. Crie um banco de dados MySQL e importe o esquema do projeto.

3. Configure as variáveis de ambiente para acessar o banco de dados.

4. Execute o projeto.

## Uso

Você pode usar a API através dos seguintes endpoints:

- [**Java 8**](https://www.oracle.com/technetwork/pt/java/javase/downloads/jdk8-downloads-2133151.html);
- [**MySQL**](https://www.mysql.com/);
 - **POST**: /users
 - **GET ALL**: /users/
 - **GET**: /users/{id}
 - **DELETE**: /users/{id}
 - **PUT**: /users/{id}
- [**Swagger**](https://swagger.io/): /swagger-ui.html;

## Documentação

Você pode acessar a documentação da API através do Swagger:

- [Swagger](http://localhost:8080/swagger-ui.html)
